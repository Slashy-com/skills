# Slashy Skills

Agent skills for [Slashy](https://slashy.com), the AI email client.

## Install

```bash
npx skills add Slashy-com/skills
```

Works with Claude Code, Cursor, Codex, Copilot, Windsurf, and any other agent supported by the [skills CLI](https://skills.sh).

## Skills

| Skill | What it does |
|-------|--------------|
| [`slashy-mcp`](skills/slashy-mcp/SKILL.md) | Teaches your agent to use the Slashy MCP server for email, calendar, meeting prep, contact research, and scheduled workflows — including setup, deep links, and attachment handling. |
